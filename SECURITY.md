# Security and data-handling rules

This repository may describe private research, laboratory tasks, and historical server structure. Keep it free of credentials and unapproved raw data.

Never commit or upload:

- `auth.json`, `secrets/`, OAuth refresh tokens, rclone configuration, or API tokens;
- Kaggle API credentials, SSH private keys, passwords, cookies, or browser profiles;
- unapproved competition data, laboratory data, or other restricted data;
- raw Codex session archives or database backups.

Use GitHub for sanitized code, documentation, manifests, checksums, and reproducibility instructions. Store encrypted recovery archives and large approved artifacts outside GitHub. Before publishing any material, verify its ownership, competition license, laboratory policy, and whether it contains personal or secret data.
